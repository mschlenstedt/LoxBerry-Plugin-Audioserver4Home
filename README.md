# LoxBerry-Plugin-AudioServer4Home
A LoxBerry Plugin. https://wiki.loxberry.de

Runs and updates the AudioServer as a Docker container:
[sonn core](https://github.com/sonn-audio/core) (`ghcr.io/sonn-audio/core`),
formerly known as lox-audioserver (`ghcr.io/lox-audioserver/lox-audioserver`).
Existing installations are migrated automatically during the plugin upgrade.
